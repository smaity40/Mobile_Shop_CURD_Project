# 📱 Mobile Shop CRUD Project

A simple **Python-based Mobile Shop Management System** that performs basic CRUD operations using a Python list.

##  Features

* Add Mobile
* Display All Mobiles
* Search Mobile
* Update Mobile
* Delete Mobile
* Exit

## 🗃️ Data Structure

Each mobile is stored as:

```python
[id, brand, model, price, quantity]
```

Example:

```python
[101, "Samsung", "Galaxy A55", 35000, 5]
```

## 🛠️ Technologies

* Python 3
* Lists
* Functions
* Loops
* CRUD Operations

## ▶️ Run

```bash
git clone https://github.com/smaity40/Mobile_Shop_CURD_Project.git
cd Mobile_Shop_CURD_Project
python main.py
```
